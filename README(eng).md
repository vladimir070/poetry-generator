# Markov Chain Poetry Generator

Poem generator using Markov chains, thematic dictionaries and rhyme system.

## Requirements
- Python 3.8+
- Libraries: `nltk`, `random`

## Install dependencies:
pip install nltk

## Usage
python poetry_generator.py

Architecture
MarkovGenerator - builds Markov chains
RhymeEngine - rhyme detection system
PoetryGenerator - main generator class

- Sample output:

Frost etches tales on windowpanes.
The comet trails celestial chains.
Beneath the bark, old secrets sleep.
The nightingale's lament runs deep.
